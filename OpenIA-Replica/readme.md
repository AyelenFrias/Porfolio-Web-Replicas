# Réplica de interfaz web de OpenAI

Proyecto de desarrollo frontend realizado como parte de mi portfolio profesional.

Este proyecto consiste en una recreación de la interfaz web de OpenAI, desarrollada con fines educativos, de práctica y demostración. El objetivo es trabajar y documentar la implementación de una interfaz existente mediante código propio, aplicando conceptos de estructura, maquetación, estilos y diseño responsive.

## Tecnologías utilizadas

- HTML5
- CSS3
- Diseño responsive

> Esta sección podrá actualizarse a medida que se incorporen nuevas tecnologías o funcionalidades al proyecto.

## Objetivos del proyecto

- Practicar la construcción de interfaces web a partir de una referencia visual.
- Aplicar HTML semántico y organización de estilos CSS.
- Trabajar la adaptación de la interfaz a diferentes tamaños de pantalla.
- Mantener una estructura de código clara y organizada.
- Documentar el proceso de desarrollo dentro de mi portfolio.
